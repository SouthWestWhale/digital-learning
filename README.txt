== Digital Learning — เว็บเรียนวิชา Digital ==

วิธีใช้:
  1. ดับเบิลคลิกไฟล์ index.html  (เปิดด้วย Edge หรือ Chrome)
  2. เลือกบทเรียนจากเมนูด้านซ้าย
  3. ทุกบทมีวงจรให้กดเล่นจริง — กดสวิตช์เปลี่ยนค่า 0/1 และกดปุ่ม Pulse Clock
     สำหรับวงจรที่มี Flip-Flop แล้วดูเส้นสายไฟ/LED เปลี่ยนตาม

หมายเหตุ:
  - เว็บนี้ใช้ออฟไลน์ได้ทั้งหมด ไม่ต้องต่อเน็ต
  - สไลด์ PDF บทเรียนอยู่ในโฟลเดอร์ docs/ เปิดได้จากหน้า "เอกสารประกอบ"
  - ความคืบหน้าการเรียน (เช็คอ่านแล้ว) ถูกเก็บในเบราว์เซอร์
    ถ้าลบข้อมูลเบราว์เซอร์หรือย้ายโฟลเดอร์ ความคืบหน้าจะหาย

สร้างเมื่อ: 28 ตุลาคม 2026
